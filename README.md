# رحلتي مع المتحدث الصغير

**أداة صفّية بسيطة للتدريس، دون حساب معلّم أو طالب ودون تسجيل دخول.** يفتح المعلّم الحصص ويستخدمها مع الصف، ويمكنه إدخال الأسماء اختياريًا واختيار المتحدث بعجلة دوّارة.

تطوير للمشروع الأصلي، لا مشروع بديل: خارطة عربية RTL من **32 حصة أصلية** في عالمين:

- **المتحدث الواثق** — الحصص 1–16، مروج ربيعية خضراء.
- **المتحدث المؤثر والمطبق** — الحصص 17–32، تلال ذهبية عند الغروب.

لم تتغيّر عناوين الحصص أو ترتيبها، ولا رسومات ليلى وسامي والأخت على الخارطة. شرائح الحصة تستخدم مكتبة «شخصيات المتحدث» (انظر أدناه). الوسام والتاج للاحتفال، وليسا حصتين إضافيتين. يحتفظ المشهد بالعشب الزاهي والأزرق والذهبي الأصليين، ويملأ الشاشة دون شريط علوي أو سفلي؛ الأدوات عائمة فوقه.

## التشغيل

يتطلب Node.js **22.12 أو أحدث**:

```bash
npm ci
npm run dev
```

يفتح Vite على `0.0.0.0:5173` ويقبل مضيف المعاينة. **لا ملف بيئة مطلوب، ولا Supabase، ولا بريد أو كلمة مرور أو رمز دخول.** الخطوط والشخصيات محلية وليست من CDN.

## أثناء التدريس

1. اضغط **«ابدأ الحصة»** على بطاقة المحطة الحالية. الحصة الأولى عرض مشاهد تعليمي من **18 شريحة** موزعة على ست مراحل موقّتة؛ تُعرض على مساحة كاملة بلا أزرار تنقّل أو شريط تقدّم داخل الشريحة. استخدم السهم الأيسر أو المسافة للتقدّم، والسهم الأيمن للرجوع، أو اسحب أفقيًا على الهاتف؛ يخرج المعلم إلى الخارطة بمفتاح Escape. بقية الحصص تحتفظ بعناصر تنقّلها المعتادة.
2. في شريحة النهاية اضغط **«إنهاء الحصة»**، أو استخدم زر **«الحصص»** على الخارطة لإنهاء الحصة وفتح التالية. كل ضغطة مقصودة تُنهي خطوة واحدة؛ فتح الحصة أو مراجعتها أو التنقّل بين شرائحها لا ينهيها تلقائيًا. إذا طال محتوى قسمٍ ما يُوزَّع آليًا على شرائح إضافية مرقّمة بدل قصّه أو تصغير خطّه.
3. من **«الحصص»** يمكنك التراجع عن آخر خطوة، أو بدء رحلة جديدة بعد تأكيد. إعادة الرحلة لا تحذف أسماء الطلبة.
4. زر **«محطتي»** يعيدك إلى موضعك. يمكن التنقّل بالعجلة والسحب واللمس والأسهم، واختيار أيٍّ من العالمين.

التقدّم **للصف كله** في هذه الرحلة، وليس سجلات أو حسابات منفصلة لكل طالب. يبدأ من الحصة الأولى ويفتح الحصص بالتسلسل. لا يوجد PIN أو إعداد حساب عند أول زيارة.

## عرض الحصة وشخصيات المتحدث

- **المنهج**: الحصة الأولى مدتها **90 دقيقة** في ست مراحل (10، 15، 20، 15، 20، و10 دقائق)، وتحتفظ بشرائحها الـ18 المعتمدة: تهيئة، سؤال للتفكير، معنى التعريف، معلومات المشاركة والخصوصية، بناء مثال مترابط، تدريب، تطبيق، إنصات، ثم تقويم وختام. تسجّل البيانات وظيفة تربوية لكل شريحة لخطة المعلم، ولا تحوّلها إلى نص واجهة ظاهر.
- **لغة العرض الأولى**: تحليل المرجع يقود إلى شخصية كبيرة داخل المشهد، فكرة رئيسية ضخمة، مثال أو سؤال يتلوها، ومساحات فارغة ومسار بصري واضح. لذلك أصبحت الحصة الأولى لوحات كاملة بلا بطاقة تطبيق أو عنوان جارٍ أو عدّاد أو شريط تقدّم. تتغير التكوينات بحسب الدور: طريق مرسوم لمراحل اليوم، سؤال مفتوح للتفكير، فقاعات أفكار، موازنة للمشاركة الآمنة، جملة نموذجية تتكشف جزءًا بعد جزء، ورقة كلمات مفتاحية، ممثلون في مساحة واحدة، مشهد حوار للاستماع، ونجمة ختام. تستخدم الشرائح رسومات شفافة منفصلة، والشخصية تؤدي دورًا داخل المشهد.
- **الحصص الأخرى**: تحتفظ الحصص 2–32 بتخطيط بطاقتها الحالي، غلاف العالم، الهدف، النشاط، التحدي، النهاية، وأدوات التنقل.
- **الحركة**: الانتقال بين الشرائح انزلاقي 0.45 ثانية باتجاه العربية. تظهر محطات الرحلة وأجزاء النموذج بتدرّج قصير، وتُطفأ الحركة مع `prefers-reduced-motion`.
- **تقليل الحركة**: مع `prefers-reduced-motion` تُطفأ كل الحركات (لا انزلاق ولا تنفّس ولا نثار) وتظهر الشريحة مباشرة.
- **الشخصيات** من مجلد «شخصيات المتحدث» على Google Drive، مقصوصة بخلفية شفافة (WebP، ارتفاع 720px، نحو 35–59 KB)، ومسجّلة في `src/components/Character.tsx`. الربط في `src/lib/lessonCast.ts`:

| الموقف                | الوضعية                                      | الملف                                     |
| --------------------- | -------------------------------------------- | ----------------------------------------- |
| العنوان / الترحيب     | ليلى تلوّح                                    | `laila-wave.webp`                         |
| النشاط                | ليلى أو سامي يشرحان (بالتناوب حسب رقم الحصة) | `laila-explain.webp`, `sami-explain.webp` |
| هدفي اليوم            | الأخت الصغيرة «لديّ فكرة!»                    | `sister-idea.webp`                        |

## أسماء الطلبة والعجلة الدوّارة

- اضغط **«مَن يتحدث؟»** من الخارطة أو من رمز الميكروفون في عرض الحصة الأولى؛ في بقية الشرائح يظهر زر الأداة المعتاد. عند إغلاق العجلة تعود إلى الشريحة نفسها.
- أدخل اسمًا في كل سطر ثم **«حفظ الأسماء»**. يمكن أيضًا فصل الأسماء بفواصل عربية أو لاتينية. الأسطر الفارغة والتكرار تُزال تلقائيًا.
- الأسماء اختيارية: يمكن تدريس الحصص دون إدخال أي اسم. تدعم القائمة حتى **60 اسمًا**، و**40 محرفًا** للاسم؛ يمكن تعديلها أو حذفها من المحرّر نفسه.
- اضغط **«أدر العجلة»** لاختيار متحدث عشوائي. يتوقف القطاع تحت المؤشر عند الاسم الذي يظهر أسفل العجلة.
- **«دون تكرار حتى يشارك الجميع»** مفعّل افتراضيًا، ويمكن إلغاؤه. بعد مشاركة الجميع اضغط **«جولة جديدة»**؛ لا يتغير تقدّم الحصص.
- عند كثرة الأسماء تظهر أرقام القطاعات المطابقة لأرقام القائمة، ويظهر الاسم الكامل في النتيجة. إغلاق العجلة أثناء دورانها يلغي القرعة دون احتساب مشاركة.
- الاختيار يستخدم مصدر العشوائية في المتصفح مع توزيع متساوٍ على الأسماء المتاحة. وضع تقليل الحركة يعرض النتيجة دون دوران طويل، ويعلنها لقارئ الشاشة.

## حفظ البيانات

الأسماء والتقدّم وإعداد الجولة تُحفظ **محليًا في هذا المتصفح فقط**. لا تُرسل أسماء الطلبة إلى خادم، ولا تُنشأ ملفات شخصية أو رموز دخول.

- لا مزامنة بين الأجهزة؛ استخدام متصفح أو نطاق آخر يبدأ بيانات مستقلة.
- مسح بيانات الموقع يحذف الأسماء والتقدّم المحفوظين.
- إذا منع المتصفح التخزين، تبقى الأدوات قابلة للاستخدام في الذاكرة، ويظهر تنبيه بأن البيانات لهذه الجلسة فقط.
- هذه أداة تدريس تعاونية، **وليست نظام صلاحيات أو سجلًا محميًا من تعديل صاحب الجهاز**. حفظ التقدّم محلي مقصود حسب الاستخدام الجديد.

## التحقق

```bash
npm run typecheck
npm test
npm run test:e2e
npm run build
```

تشمل الاختبارات ثبات الحصص والشخصيات، تصادمات الخارطة، الحفظ المحلي، تسلسل الحصص، إدخال الأسماء، العشوائية وعدم التكرار، ملاءمة الهاتف والحاسوب، التنقّل وإمكانية الوصول. تُختبر الشاشات `1920×1080` و`1440×900` و`1366×768` و`1024×768` و`820×1180` و`390×844` عند الأعداد `0، 7، 16، 20، 32`.

الصور في `artifacts/screenshots/` وتقارير axe في `artifacts/axe-*.json` وتقرير المتصفح في `playwright-report/`. جميع المخرجات مستثناة من Git. راجع [تقرير التحقق](docs/verification.md).

اختبارات المتصفح تستخدم Chromium موزعًا عبر npm على Linux x64. على الأنظمة الأخرى ثبّت المتصفح المعتاد بـ `npx playwright install chromium`.
