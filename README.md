# 🎤 رحلتي مع المتحدث الصغير — الخارطة التفاعلية

خارطة تعليمية تفاعلية لبرنامج **المتحدث الصغير** (32 حصة في مستويين). تعرض الخارطة جميع المحطات منذ البداية، وتُفتح المحطات واحدة تلو الأخرى **فقط** بعد أن يعتمد المدرّب إكمال الحصة السابقة.

## التشغيل

```bash
npm install
npm run dev      # خادم التطوير على المنفذ 5173
npm run build    # نسخة الإنتاج في مجلد dist
```

## ما الذي تحتويه

| الجزء | الوصف |
| --- | --- |
| **المنطقة الأولى: المتحدث الواثق** | الحصص 1 → 16، بطابع سماوي أزرق |
| **المنطقة الثانية: المتحدث المؤثر والمطبق** | الحصص 17 → 32، بطابع بنفسجي دافئ. تبقى باهتة حتى يكتمل المستوى الأول |
| **محطات الإنجاز** | «وسام المتحدث الواثق» بعد الحصة 16، و«تاج المتحدث المؤثر» بعد الحصة 32، مع احتفال قصير وهادئ |
| **الشخصيات** | الأخت الصغيرة ترافق الطفل في نقطة الانطلاق، وليلى تقف بجانب المحطة الحالية وتشير إليها، وسامي يشجّع الطفل عند محطات الإنجاز ويحتفل عند بلوغها |

### حالات المحطات
- **متاحة الآن**: مضيئة بنبض خفيف، مع رقم الحصة وعنوانها وزر «ابدأ الحصة».
- **مقفلة**: قفل ثابت وألوان هادئة. عند الضغط تظهر: «هذه المحطة لم تُفتح بعد. أكمل رحلتك للوصول إليها».
- **مكتملة**: لون أخضر مميّز مع علامة ✓ وزر «مراجعة الحصة».
- **محطات الإنجاز**: تصميم احتفالي عند نهاية كل مستوى.

## آلية الفتح (لوحة المدرّب)

- الحالة الابتدائية: الحصة 1 مفتوحة، والحصص 2 → 32 مقفلة.
- الطفل **لا يستطيع** فتح أي حصة بنفسه. حتى الرابط المباشر لحصة مقفلة (`#/lesson/12`) يُعاد إلى الخارطة.
- زر 🔑 (أسفل الشاشة) يفتح **لوحة المدرّب** المحمية برمز من 4 إلى 8 أرقام. يُطلب إنشاء الرمز عند أول استخدام، ولا يُحفظ إلا بعد تجزئته (hash).
- من اللوحة: **«اعتماد إكمال الحصة N وفتح الحصة N+1»** بعد تأكيد. الاعتماد يكون دائمًا للحصة الحالية فقط، فلا يمكن تجاوز أي حصة.
- أدوات إضافية: التراجع عن آخر اعتماد، وإعادة ضبط الرحلة، وتغيير الرمز، وإضافة اسم الطفل ليظهر في العنوان.
- بعد الاعتماد يظهر على الخارطة تأثير فتح القفل، ثم تضيء المحطة الجديدة. عند إتمام مستوى كامل يظهر احتفال قصير، وتنتقل الشخصيات إلى المنطقة التالية.

> التقدّم محفوظ حاليًا في المتصفح (`localStorage`) على الجهاز نفسه. لمزامنة التقدّم بين جهاز المدرّب وجهاز الطفل، يكفي استبدال دالتَي `loadRaw / saveRaw` في `src/lib/progress.ts` بقاعدة بيانات (مثل Supabase)، دون تغيير بقية الواجهة.

## هيكل الملفات

```
src/
  data/sessions.ts        ← الحصص الـ32 بعناوينها الأصلية + وصف قصير وأيقونة لكل حصة
  lib/progress.ts         ← حالة التقدّم وقواعد الفتح (approveNext / undoLast …)
  lib/pin.ts              ← تجزئة رمز المدرّب
  components/JourneyMap   ← الخارطة: الطريق المتعرّج والمنطقتان والمحطات
  components/Station      ← محطة واحدة بحالاتها
  components/StationSheet ← البطاقة التي تظهر عند الضغط على محطة
  components/LessonView   ← شاشة الحصة (ضع فيها محتوى كل حصة)
  components/TeacherPanel ← لوحة المدرّب
  components/Celebration  ← احتفال إتمام المستوى
public/characters/        ← صور ليلى وسامي والأخت الصغيرة (بخلفية شفافة)
```

## إمكانية الوصول
- واجهة عربية بالكامل واتجاه RTL، بخطَّي Tajawal وBaloo Bhaijaan 2 (مضمّنين محليًا).
- متجاوبة مع الحاسوب واللوحي والهاتف، وتظهر البطاقات على الهاتف كلوحة سفلية.
- أزرار كبيرة، ودعم للوحة المفاتيح (Esc للإغلاق)، واحترام إعداد «تقليل الحركة» `prefers-reduced-motion`.
