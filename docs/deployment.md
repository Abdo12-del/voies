## التشغيل لا يحتاج خادمًا أو حسابات

التطبيق الحالي واجهة صفّية محلية بالكامل. لا تحتاج إلى مشروع Supabase أو متغيرات بيئة أو إنشاء حساب معلّم. أُزيل عميل Supabase من الاعتماديات ومكونات تسجيل الدخول من التطبيق.

متغيرا `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY` اللذان أُعدّا سابقًا لا تُقرأ قيمهما في هذه النسخة، ولا تُجرى طلبات Auth أو Realtime أو REST. لم تُحذف موارد الحساب السحابية السابقة أو تُغيّر إعداداتها؛ توثيقها أرشيف في `supabase.md` فقط.

البيانات في `localStorage` لهذا الأصل في المتصفح:

| المفتاح                       | المحتوى                                                          |
| ----------------------------- | ---------------------------------------------------------------- |
| `voies.classroom-progress.v1` | عدد الحصص المكتملة واحتفال ينتظر العرض                           |
| `voies.classroom-names.v1`    | أسماء اختيارية، المشاركون في الجولة، آخر متحدث، خيار عدم التكرار |

هذه ليست بيانات تسجيل دخول ولا صلاحيات. كل جهاز ومتصفح ونطاق يحتفظ ببياناته المستقلة؛ رابط المعاينة الفريد ليس هو أصل رابط الفرع الثابت. يُنصح باستعمال رابط ثابت أثناء التدريس حتى تستمر البيانات المحلية.

## النشر التلقائي

يستخدم المشروع تكامل Vercel الأصلي مع Git، لا مهمة نشر ثانية في GitHub Actions:

```json
{
  "git": { "deploymentEnabled": true },
  "github": { "autoJobCancelation": false }
}
```

الدفع إلى فرع العمل ينشئ معاينة، والدمج إلى `main` ينشئ نشر إنتاج. تأكد نجاح `READY` ومطابقة SHA في Vercel بعد كل نشر. لا حاجة إلى `VERCEL_TOKEN` أو مفاتيح خادم في حزمة الواجهة.

تختبر GitHub Actions الأنواع والوحدات والبناء والمتصفح. رفع الصور خطوة إضافية بأفضل جهد وبمهلة محددة، ولا يُخفى فشل اختبار أو بناء.

## المعاينة المحمية

حماية معاينات Vercel الحالية إعداد استضافة منفصل عن التطبيق. قد تطلب المعاينة حساب Vercel المصرّح له؛ هذا **ليس دخول طالب أو معلّم داخل المنصة**. لم نغيّر حماية حساب الاستضافة. معاينة التطوير المحلية تفتح التطبيق مباشرة دون أي حسابات.

## بعد الموافقة والدمج

طلب التغيير [#2](https://github.com/Abdo12-del/voies/pull/2) لم يُدمج ضمن هذه الجولة؛ بقي الإنتاج على النسخة السابقة.

1. راجع نشر الإنتاج وتأكد من SHA الدمج والحالة `READY`.
2. افتح التطبيق: يجب أن تبدأ الحصة الأولى دون بريد أو رمز أو كلمة مرور.
3. أدخل أسماء اختبار، أدر العجلة، ثم أعد تحميل الصفحة للتحقق من الحفظ المحلي.
4. أنهِ حصة واحدة وتراجع عنها، وتحقق من عدم ارتباط تقدّم الرحلة بأسماء الطلبة.
5. امسح بيانات الاختبار من محرّر الأسماء وأعد الرحلة إن لزم. لا حسابات سحابية ينبغي إنشاؤها أو مشاركتها مع الطلبة.
