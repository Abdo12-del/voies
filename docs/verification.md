# تقرير التحقق — النسخة الصفّية، 11 نوفمبر 2026

## النطاق الحالي

حسب توضيح صاحب المشروع، هذه منصة يستخدمها للتدريس مع الصف، **بلا حساب طالب أو معلّم**. أُزيل تسجيل الدخول والرموز وعميل Supabase من الواجهة، واستُبدل التقدّم الفردي بتقدّم صفّي محلي بسيط. أسماء الطلبة ميزة اختيارية للعجلة، وليست ملفات شخصية أو سجلات تقدّم.

لم تتغير الحصص الـ32 أو ترتيبها أو الأهداف الفردية أو ملفات الشخصيات الستة. بقيت الخلفية كاملة الشاشة والعشب الزاهي والأزرق والذهبي والأدوات العائمة، دون أشرطة علوية أو سفلية.

## تبسيط المنصة والحفظ المحلي

- تبدأ الحصة الأولى مباشرة، دون شبكة تسجيل دخول أو متغيرات بيئة أو وضع عرض تجريبي مقفل.
- فتح الحصة أو مراجعتها لا يُنهيها. زر إنهاء الحصة أو إدارة الحصص ينقل التقدّم خطوة واحدة فقط؛ الضغط المكرر بالعدد القديم لا ينشئ خطوة ثانية.
- التراجع خطوة واحدة، وإعادة الرحلة تحتاج تأكيدًا. إعادة الرحلة لا تمس أسماء الطلبة.
- الحفظ يستمر بعد إعادة تحميل الصفحة. تُتجاهل سجلات النسخة الفردية القديمة بدل نقل PIN أو حساب طالب إلى الصف.
- يُتحقق من بنية البيانات المحلية ونطاق العدد 0–32؛ السجلات التالفة لا تكسر الواجهة. عند منع التخزين تستمر الأدوات في الذاكرة مع تنبيه واضح.
- هذه أداة صفّية تعاونية. **لا ندّعي حماية محلية من صاحب الجهاز أو مزامنة بين أجهزة مختلفة أو حسابات وصلاحيات سحابية.**

## الأسماء والعجلة

- إدخال مباشر، اسم في كل سطر أو أسماء مفصولة بفواصل، مع حذف الأسطر الفارغة والتكرار وتحديد 60 اسمًا و40 محرفًا للاسم.
- الأسماء اختيارية، لا تُرسل إلى خادم ولا تؤثر في تقدّم الحصص.
- اختيار عشوائي من الأسماء المتاحة باستخدام `crypto.getRandomValues` ورفض الطرف المنحاز قبل باقي القسمة.
- تطابق رياضي ومقارنة متصفح بين قطاع المؤشر والاسم المعلن، لأحجام صفوف مختلفة، بما فيها اسم واحد و60 اسمًا.
- عدم تكرار الاسم حتى يشارك الجميع، وحفظ الجولة عند الإغلاق/إعادة التحميل، وإعادة الجولة وتفعيل التكرار اختياريًا.
- تغيير الأسماء يعيد الجولة فقط. النص المدخل يعرضه React كنص، لا HTML؛ اختُبر اسم يحتوي وسم صورة دون إنشاء عنصر صورة.
- الدوران العادي يعطّل سحب قرعة أخرى وتعديل الأسماء، ولا يكشف النتيجة قبل النهاية. إغلاق الحوار أثناء الدوران يلغي المؤقّت والقرعة.
- في وضع تقليل الحركة تظهر النتيجة دون دوران طويل. توجد منطقة إعلان لقارئ الشاشة، وتركيز قابل للوحة المفاتيح في قائمة الأسماء القابلة للتمرير.
- العجلة متاحة من الخارطة ومن شاشة الحصة نفسها، وتعود بؤرة التركيز إلى زر فتحها بعد الإغلاق.

فُحص ملء النافذة `(0, 0, width, height)`، شفافية حاويات الأدوات وعدم وجود أشرطة، عدم التمرير الرأسي، عدم تداخل عناصر المشهد أو الأدوات، مساحة بطاقة الحصة، النصوص، توسيط المحطة، وألا تتجاوز الزينة 10% من مساحة المشهد. نجحت العجلة الأفقية والسحب واللمس وأسهم الحواف ولوحة المفاتيح والتبديل بين العالمين و«محطتي».

للأعداد أقل من 32 زر «ابدأ الحصة» واحد فقط؛ بعد إتمام الرحلة لا زر بدء أو حصة حالية. الوسام والتاج ليسا حصتين إضافيتين. اختُبر أن احتفال المستوى لا يعاود الظهور عند إعادة التحميل بعد إغلاقه.

## إمكانية الوصول والصور

axe يفحص الخارطة الخضراء والعالم الذهبي والاحتفال والحوار وشاشة الحصة وإدارة الحصص، ومحرّر الأسماء والعجلة ونتيجتها على الهاتف والحاسوب. نتائج الفحوص في `artifacts/axe-*.json`. يوجد أيضًا اختبار مستقل للتباين 4.5:1 على لوحات الألوان المختبرة، بما فيها العناوين المخفية بصريًا عن تحليل axe والممثلة بأسماء أزرارها.

الصور في `artifacts/screenshots/`، ومنها 42 صورة للخارطة والاحتفال وصورتا العجلة `classroom-wheel-1440x900.png` و`classroom-wheel-390x844.png`. الأسماء في الأدلة بيانات اختبار، وليست بيانات أطفال فعلية. الصور وتقارير المتصفح مستثناة من Git.

تجمَّد حركة المشهد خلف الحوار المفتوح لتخفيف التشتيت وإعادة الرسم؛ العجلة داخل بوابة الحوار تظل قادرة على الدوران. بقي حبس التركيز وEscape واستعادة التركيز واحترام تقليل الحركة.

## حدود التحقق والنشر

- اختبارات المتصفح تستخدم تنسيق التخزين المحلي الموثق؛ لا يوجد عميل سحابي محاكى أو مدخل اختبار سري في تطبيق الإنتاج.
- لم نختبر يدويًا Safari/Firefox أو قارئات VoiceOver/NVDA أو فقدان التخزين في جميع المتصفحات. التخزين المحظور والتالف مختبر في وحدات المنطق.
- الملفات السحابية القديمة و14 اختبار SQL محفوظة كمرجع تاريخي فقط. لم تُغيّر الموارد أو السياسات أو إعدادات مشاريع Supabase في هذه المراجعة، ولا يلزم إنشاء حساب معلّم أو اختبار Realtime لتشغيل النسخة الحالية.
- النشر بواسطة تكامل Vercel Git الموجود. لا يعني نجاح الفحوص المحلية اكتمال تشغيل GitHub Actions الحالي؛ تُراجع حالته من PR.
- طلب التغيير #2 لم يُدمج إلى `main` في هذه الجولة، لذا الإنتاج السابق لم يُستبدل بعد. حماية معاينة Vercel إعداد استضافة منفصل عن عدم وجود حسابات في التطبيق؛ راجع `docs/deployment.md`.
